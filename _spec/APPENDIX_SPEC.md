## 必须覆盖的内容（一条样本：**训练对「我爱你 → I love you」**）

### A.1 样本的一生总览图（一幅大 SVG 时间线）
横向五幕：语料清洗 → tokenize → 训练 step（前向+损失+反传+Adam 更新）→ 保存权重 → 推理生成。每幕标注「输入是什么 / 张量形状 / 输出去哪」。

### A.2 第一幕：从网页到 token 序列
- 语料：一对平行句「我爱你 ⇆ I love you」（真实场景来自大规模清洗后的语料，提一句质量过滤）。
- 分词（用简化的词级分词，诚实标注"真实模型用 BPE 子词"）：`我 爱 你` → id `[1024, 837, 2055]`（自编 id 但全文一致）；英文侧加特殊符号：`<s> I love you </s>`。
- 给出张量：源 [3]，目标输入 [<s>, I, love, you] = [4]，目标标签 [I, love, you, </s>] = [4]（**错位一格**——教师强制的关键，表格展示"输入往右挪一格就是标签"）。

### A.3 第二幕：训练时的前向传播（对这条样本）
- 嵌入+位置编码：源 [3×512]、目标 [4×512]（标注查表 + 加 PE）。
- 编码器 6 层（每层：自注意力 QK^T 是 [3×3]、FFN 升 2048、Add&Norm）→ 输出笔记 H [3×512]。
- 解码器 6 层（每步掩码自注意力 [4×4] 上三角 −∞、交叉注意力分数 [4×3]、FFN）→ 输出 [4×512]。
- 输出头：[4×512] × [512×37000] → logits [4×37000] → softmax → 4 个位置各一个 37000 维分布。
- **把注意力读什么写具体**：给一个合理的小例子——解码器在预测 "love" 时，交叉注意力对「我/爱/你」的权重约为 (0.08, 0.74, 0.18)，即主要读「爱」。注明"数值为教学示意"。

### A.4 第三幕：这条样本的损失与参数更新（本章核心账）
- 逐位置损失手算表：假设前向给出正确词的概率为 I:0.62、love:0.48、you:0.71、</s>:0.55（示意值），损失分别为 −ln p = 0.478 / 0.734 / 0.342 / 0.598，样本损失 = 平均 = 0.538（必须用 node 算准）。
- 反向传播直觉：对每个位置，梯度把"正确词的 logits 往上推、其他词往下压"，力度正比于 (p_model − 1)——模型越自信错得越少。用 3 行的迷你词表例子算一遍梯度方向（softmax+CE 的梯度 = p − y，这个公式可以给出并手算：如某位置 p=(0.62,0.25,0.13)、y=(1,0,0) → 梯度=(−0.38, 0.25, 0.13)，解释为"正确词减 0.38，错误词加"，注意这是 logits 层的梯度）。
- 一步 Adam 更新：θ ← θ − lr · m̂/(√v̂+ε)。给出直觉版本即可：这条样本让"爱→love"这条通路的所有相关权重都被轻轻推了一把（一次 step 只改一点点，因为 lr 很小且是 batch 平均）。给出数量级感觉：一次更新对单个权重的典型改变 ~1e-5 量级（注明"数量级示意"）。
- 强调：同一台机器对**整个 batch**（原论文 ~25000 token/批）同时做这件事，然后取下一条。

### A.5 第四幕：训练完成后，同一句子的推理生成
- 现在没有老师了：编码器照常跑一遍得 H；解码器从 <s> 开始，**每一步只生成一个词，喂回去再生成下一个**（自回归，呼应第 8 章）。
- 逐词走查表：step1 输入 [<s>] → 分布 → 选 I（0.62）；step2 输入 [<s>, I] → love；step3 → you；step4 → </s> 停止。每步标注"此刻注意力读了什么"（解码自注意力只能看已生成前缀；交叉注意力每步都读整份 H）。
- 与训练时对比表：训练=并行+喂真标签（快）；推理=串行+喂自己的输出（慢，但有 KV cache——每步只需为新词算注意力，呼应第 8 章的账）。
