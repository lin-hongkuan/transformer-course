# 「样本的一生」旗舰交互演示规格 —— demos/demo-journey.html

先 Read G:\Research\transformer-course\_spec\SHARED_SPEC.md（demo 规范）与 _spec\APPENDIX_SPEC.md（内容事实源）。可参考 demos\demo-architecture.html 的结构写法（Read 它）。scoped 前缀 `.dz-jr`。vanilla JS IIFE + try/catch。颜色只用 var(--…) 框架变量。

## 定位
附录 A 配套的旗舰演示：**跟着同一条训练样本「我爱你 → I love you」走完一生**。一条横向五幕流水线 + 中央舞台 + 底部解说栏。所有数值与 part09 附录 A 正文完全一致（写之前先 Read parts\part09.html 里附录 A 最终落盘的数字，以它为准；若附录 A 尚未落盘，以 APPENDIX_SPEC.md 的数字为准）。

## 结构
顶部：五幕流水线导航（① 语料与分词 ② 训练·前向 ③ 训练·损失与更新 ④ 保存 ⑤ 推理生成），每幕一个可点击站点；另有「播放全程」「单步 →」「← 上一步」「重置」按钮。
中央舞台（随幕切换内容）：
- **幕 1 语料与分词**：平行句对卡片「我爱你 ⇆ I love you」→ token id 序列动画（词块逐一翻牌成 id：[1024, 837, 2055] / [<s>, I, love, you, </s>]），并展示"目标输入 vs 目标标签错位一格"的对位表。
- **幕 2 训练前向**：简化的编码器→解码器图。数据包高亮流动：源 [3×512] 进编码器（内部小动画：3×3 自注意力热力图亮一下）→ H[3×512]；解码器输入 [4×512]（掩码自注意力 [4×4] 三角热力图 + 交叉注意力 [4×3] 热力图，交叉注意力上标注"预测 love 时读：我 0.08 / 爱 0.74 / 你 0.18"）；输出 logits [4×37000] → 每个位置的概率条形（标出正确词概率 0.62/0.48/0.71/0.55）。
- **幕 3 损失与更新**：逐位置损失条形图（0.478/0.734/0.342/0.598 → 均值 0.538）；然后一个「p − y 梯度」小动画：某个位置的分布条形里，正确词的条往下缩短、错误词的条往上长一点（梯度方向可视化）；最后显示"θ ← θ − lr·…：这条样本把『爱→love』通路轻轻推了一把"。
- **幕 4 保存**：权重文件卡片（"约 63M 个浮点数写入磁盘"），短暂过场。
- **幕 5 推理生成**：自回归循环动画：解码器逐词吐出 I → love → you → </s>，每步显示该步的概率分布小条形与"已生成前缀"增长；旁边标注"训练时一次算完 4 个位置；推理时只能一个一个来（KV cache 帮忙提速）"。

## 控件与行为
- 单步：在五幕内部的子步骤间步进（总步数约 18~24 步），状态栏同步中文解说（每步一句话，讲清"此刻输入是什么/形状/谁在读谁/输出去哪"）。
- 播放：自动按 ~1.6s 间隔走完全程，可随时暂停；走完显示「这条样本的一生走完了」并可重播。
- 点流水线站点可直接跳到某幕开头。
- 全部数值从页面顶部的 `const DATA = {...}` 单一来源读取，便于核对。
- 手机端：流水线允许横向滚动，舞台内容 100% 宽自适应。
