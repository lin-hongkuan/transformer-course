第 5 章 · 前馈网络与残差/层归一化

让信息稳定地流过六层高楼

学完第 3 章和第 4 章，你已经掌握了 Transformer 的心脏——注意力。但一个完整的 Transformer 层里，注意力只负责"词与词之间的交流"，还有两个关键零件等着我们：让每个词"自己思考"的前馈网络（FFN），以及让六层（甚至九十六层）高楼不会塌掉的两个稳定器：残差连接和层归一化。本章结束后，你将能手算一个完整 FFN 的前向传播，并说清楚为什么 ∂(x+F(x))/∂x 里那个"1"是深网络的救命稻草。

5.1 注意力管"交流"，那"思考"谁来管？

先回想一下我们的多层叙事。在第 3 章里，我们把注意力比作一场"圆桌会议"：每个词拿着自己的 Query（查询向量）去问别的词"你跟我的关系大吗"，然后根据答案（注意力权重）把别的词的 Value（值向量）加权搬回来。会议结束后，每个词的表示里都混入了上下文的信息。

但"开会"只是第一步。开完会，每个词还需要自己回到工位上消化：把刚刚收集到的信息加工、提炼、转换成更有用的特征。这个"独自消化"的步骤，就是前馈网络（Feed-Forward Network，简称 FFN）。

我们可以把一个 Transformer 编码器层想象成一家公司的两个固定环节：

  1. 全员大会（多头注意力）：信息在词与词之间流动。
  2. 个人工位（前馈网络）：每个词独立地对自己的信息做深加工，词与词之间此刻完全不交流。

这两个环节之外，还各缠着一条"安全带"（残差连接）和一个"调音台"（层归一化）。本章会把这个完整的车间——也就是一个标准编码器层——彻底拆开。

5.2 前馈网络：先升维，再压回来

FFN 的结构简单到出乎意料：它就是两个线性变换（乘以权重矩阵），中间夹一个非线性激活函数。原论文用的激活函数是 ReLU（Rectified Linear Unit，整流线性单元，规则就一条：正数原样通过，负数砍掉变 0）。公式如下：

FFN(x) = max(0, xW₁ + b₁)W₂ + b₂

逐符号读一遍：

  • x：某个词当前的表示向量。在原论文里它的长度是 d_model = 512，也就是 512 个数字。
  • W₁：第一层权重矩阵，形状是 [512 × 2048]——它把 512 维的输入放大到 2048 维。这个 2048 记作 d_ff，原论文里 d_ff = 2048，恰好是 d_model 的 4 倍。
  • b₁：第一层偏置向量，2048 个数字，给每个高维特征一个"基础偏移"。
  • max(0, ·)：ReLU 激活，逐元素比较，小于 0 的全部归零。
  • W₂：第二层权重矩阵，形状 [2048 × 512]，把高维结果压回 512 维。
  • b₂：第二层偏置向量，512 个数字。

所以整条流水线是：[512] → [2048] → [512]。先膨胀到 4 倍，再压缩回原样。数据形状的旅程用图表示如下。

为什么非要"先升维再降维"？

这是本章第一个值得停下来想的问题：既然最后还是回到 512 维，为什么不直接在 512 维里做变换，白白绕一圈？

想象你在揉面团。面粉、水、酵母刚混在一起时是一团黏糊糊的东西，直接塑形很困难——各种成分挤在一起、分不开。聪明的做法是先把面团揉开、摊开、拉抻，让每一种成分在大空间里舒展开，你能清楚地看到哪一团是筋、哪一块是气泡，该切的切、该留的留；处理完了再收拢塑形，变回一个紧实的面团。

FFN 干的是同样的事。一个词经过注意力之后，它的 512 维向量里塞满了刚刚收来的上下文信息，各种特征纠缠在一起。W₁ 把这团信息摊开到 2048 维的"工作台"上：在高维空间里，原本挤在一起、难以区分的特征更容易被"分开摆放"（数学上这对应一个经典事实——数据被投影到更高维后，更容易找到线性可分的划分）。然后 ReLU 扮演质检员：2048 个高维特征里，不相关的、弱的特征被打成 0 扔掉，只有被激活的强特征留下来。最后 W₂ 把筛选、重组过的精华重新压缩回 512 维，交还给主干道。

你也可以把 FFN 想成一个有 2048 位专科医生的会诊室：512 维的"病情描述"被送进会诊室，每位专科医生（高维特征）只对自己关心的模式做反应（ReLU 决定他是否开口），最后汇总结论压回 512 维病历。升维让"每位医生有自己的诊室"，这就是 4 倍扩张的意义。

激活函数的江湖

2017 年原论文用 ReLU。后来的模型发现更平滑的激活效果更好：BERT、GPT 系列早期版本常用 GELU（高斯误差线性单元，负数不完全归零，而是平滑地压向 0）；LLaMA 等现代大模型则用 SwiGLU（一种带"门控"的变体，参数量略增但表达力更强）。它们的差别属于"进阶调料"，思想都是"温和地筛选特征"，具体细节我们留到第 9 章的现代变体里展开。本章你只需要记住 ReLU 这条最朴素的规则。

5.3 Position-wise：同一个 FFN，每个词各用各的

论文里给 FFN 加了一个定语：position-wise feed-forward networks（逐位置前馈网络）。这个定语是本节的主角，它的意思是：

关键定义

同一层里只有一个 FFN（一套 W₁、b₁、W₂、b₂），它被应用到序列的每一个位置上，每个位置独立地、互不干扰地通过这同一个网络。

用"工位"类比继续：公司只配了一台"信息加工机"（FFN），开完全员大会后，每个词排队各自把材料送进去加工。机器对谁都用同一套加工参数，但加工过程是一个词一个词独立进行的——"我"进去加工的时候，完全看不到"爱"正在被加工成什么样。词与词之间的交流，已经在上一步注意力里完成了；FFN 不负责交流，只负责深加工。

假设一个序列有 6 个词（比如"我 爱 深 度 学 习"），每个词是一个 512 维向量，那么整个序列就是一个 [6 × 512] 的矩阵。FFN 作用在这 6 行上，每一行独立：

位置词输入（各自独立）经过的 FFN输出（各自独立）
0我x₀ [512]同一个 FFN
同一套 W₁ b₁ W₂ b₂		y₀ [512]
1爱x₁ [512]y₁ [512]
2深x₂ [512]y₂ [512]
3度x₃ [512]y₃ [512]
4学x₄ [512]y₄ [512]
5习x₅ [512]y₅ [512]

这张表也是理解 Transformer 并行性的钥匙：因为每个位置的 FFN 计算互不依赖，6 个词的加工可以同时在 GPU 的 6 路流水线上跑，不需要像 RNN 那样等"我"算完才能算"爱"。从矩阵角度看，整个 [6 × 512] 的矩阵乘上 W₁ [512 × 2048] 得到 [6 × 2048]，过 ReLU，再乘 W₂ 得到 [6 × 512]——数学上是矩阵乘法，效果上就是 6 个词各自过了一遍同一个 FFN。

常见混淆：FFN 里词与词会交流吗？

不会。很多人会误以为"矩阵乘法让行与行混在一起了"。请记住：FFN 的两次矩阵乘法里，权重矩阵 W₁、W₂ 只在特征维度（512/2048 这一侧）上做混合，词与词（行与行）之间没有任何交叉项。第 i 行的输出只由第 i 行的输入决定。想让词与词说话？那是注意力的职责，回到第 3 章。

5.4 手算一个迷你 FFN（d_model=2, d_ff=4）

512 和 2048 太抽象了。我们把数字缩到手能算的大小：设 d_model = 2，d_ff = 4（仍然是"4 倍升维"的精神）。给定一个词的输入向量：

x = [1, 2]

第一层参数（全是一眼能算的小数字）：

W₁ = [[1, 0, 1, −1], [0, 1, 1, 1]] ， b₁ = [0, 0, −1, 0]

第一步：计算 xW₁ + b₁。 结果有 4 个分量，逐个算（每个分量 = x 的两个元素与 W₁ 对应列做点积，再加偏置）：

  • 分量 1：1×1 + 2×0 + 0 = 1
  • 分量 2：1×0 + 2×1 + 0 = 2
  • 分量 3：1×1 + 2×1 − 1 = 2
  • 分量 4：1×(−1) + 2×1 + 0 = 1

得到升维后的中间向量 h_pre = [1, 2, 2, 1]。

第二步：过 ReLU。 这里四个数恰好都是正的，所以 ReLU 不动它们：h = [1, 2, 2, 1]。

看一眼 ReLU 的"质检"作用

假如偏置 b₁ 换成 [−3, 0, −5, 0]，中间向量会变成 [−2, 2, −2, 1]，ReLU 之后就是 [0, 2, 0, 1]——两个特征被"判定不相关"而清零。这就是为什么 ReLU 让网络具有"选择能力"：它制造出大量 0，强迫网络只让少数通道通过。

第三步：乘回 W₂ 降维。 设：

W₂ = [[1, 0], [0, 1], [1, 1], [−1, 0]] ， b₂ = [0, 1]

输出 2 个分量：

  • 分量 1：1×1 + 2×0 + 2×1 + 1×(−1) + 0 = 2
  • 分量 2：1×0 + 2×1 + 2×1 + 1×0 + 1 = 5
FFN([1, 2]) = [2, 5]

完成。[1, 2] 进去，[2, 5] 出来，中间经过了一次"2 → 4 → 2"的升维-筛选-压缩之旅。真实模型里每个数字都是训练学出来的浮点数，但流程与这个手算一模一样。本章末尾的交互演示（5.9 节）里也内置了这个迷你 FFN，你可以亲手调参数复算。

算一笔账：FFN 占了多少参数？

别忘了 FFN 是有"体重"的。回到真实数字 d_model = 512、d_ff = 2048：

参数形状数量
W₁[512 × 2048]1,048,576
b₁[2048]2,048
W₂[2048 × 512]1,048,576
b₂[512]512
合计—2,099,712 ≈ 210 万

而一层多头注意力的四个权重矩阵（W_Q、W_K、W_V、W_O，各 [512 × 512]）合计约 105 万参数。也就是说，FFN 占了每个编码器层约三分之二的参数。有一个流行的说法：注意力是"路由器"，决定信息从哪里来；FFN 是"知识库"，模型学到的大量"事实与模式"被认为主要存储在 FFN 的权重里。这也是为什么后来各种"专家混合（MoE）"结构改造的几乎都是 FFN 部分。

5.5 残差连接：给梯度修一条高速公路

现在把目光从 FFN 内部移出来，看看它外面包着的那条"安全带"。Transformer 里，每个子层（注意力、FFN）的输出都不是直接替换输入，而是：

输出 = x + Sublayer(x)

这就是残差连接（Residual Connection），也叫"跳跃连接（Skip Connection）"：把子层的输入 x 原封不动地抄一份，直接加到子层的输出上。注意这里有一个硬性要求：子层的输出维度必须和输入相同（这正是 FFN 最后要"压回 512 维"的原因之一——维度不一致就没法相加）。

类比：修订模式，而不是重写

想象你请一位编辑帮你修改文章。有两种工作方式：

  • 重写模式（没有残差）：编辑读完全文，凭记忆重新写一遍。改六轮之后，文章很可能已经面目全非——每一轮重写都可能丢掉原文的信息，而且一旦某一棒写砸了，后面所有棒都在烂稿子上继续错。
  • 修订模式（有残差）：编辑拿到你的原稿（x），只在上面做批注和改动（F(x)），交回来的是"原稿 + 批注"（x + F(x)）。哪怕某个编辑水平很差、批注全是废话，你的原稿也一字未丢；六位编辑接力之后，文章是原稿加上层层累积的修订痕迹。

残差连接让每一个子层学的不是"新的完整表示"，而是对当前表示的"增量修正"。子层就算什么都没学到（F(x) ≈ 0），网络至少退化成"原样传下去"，不会比浅层网络更差。这个性质让"堆更多层"变成一件安全的事。

为什么深网络需要它：梯度消失问题

训练神经网络靠"反向传播"：从最后的损失出发，把"该往哪个方向调参数"的信号（梯度）一层一层传回前面的层。问题在于，梯度每穿过一层，就要乘上那层的导数。如果每层的导数大约只有 0.8，那么穿过 30 层之后：

0.8³⁰ ≈ 0.00124

梯度被缩小到原来的千分之一——最前面的层几乎收不到任何训练信号，参数不动了，学不动了。这就是梯度消失（vanishing gradient）。六层也许还撑得住，几十上百层（GPT-3 有 96 层）就会彻底瘫痪。

残差连接的救命之处可以用一行数学看清楚。设输出 y = x + F(x)，那么 y 对 x 的导数是：

∂y/∂x = ∂(x + F(x))/∂x = 1 + ∂F/∂x

注意那个醒目的 "1"。反向传播经过这一层时，梯度不再只是乘上 ∂F/∂x（那个可能很小的数），而是乘上 (1 + ∂F/∂x)。就算 F 的导数接近 0，梯度也能原封不动地通过那个 "1" 传回去——就像高速公路上除了蜿蜒的辅路（F），永远有一条笔直的主干道（恒等通道 x）。N 层连乘时，这些 "1" 项保证梯度里始终存在一条不衰减的路径，深网络的每一层都能收到清晰的训练信号。

一句话记住残差连接

前向时，它是"原稿 + 批注"，信息不丢；反向时，它是梯度的高速公路，∂y/∂x 里的那个 +1 让信号永不归零。本章末尾的交互演示会让你亲眼看到这两条曲线的天壤之别。

5.6 层归一化：把每个向量调回"标准音量"

第二个稳定器是层归一化（Layer Normalization，简称 LayerNorm 或 LN）。它要解决的问题是：随着数据流过一个又一个子层，向量里数字的大小和分布会漂移——有的层输出动不动就是几十，有的层又全是零点零几。数值尺度飘来飘去，训练就会像踩着一艘不停晃动的船：激活函数容易饱和，梯度忽大忽小。

LayerNorm 的做法一句话说完：对每个词的向量，减去它自己的均值，再除以它自己的标准差，把每个向量重新拉回"均值 0、标准差 1"的标准分布。就像一个调音台，不管歌手嗓门大小，都先归一到标准音量再做混音。

LN(x) = γ ⊙ (x − μ) / √(σ² + ε) + β

其中：

  • μ：这个向量所有分量的均值（一个标量）；
  • σ²：这个向量所有分量的方差（一个标量）；
  • ε：一个极小的常数（如 10⁻⁵），防止标准差为 0 时除零，只为数值稳定；
  • γ（gamma）和 β（beta）：两个可学习的向量，长度等于 d_model。归一化之后再做一次"按分量缩放 + 平移"，让网络有权说"我不想被完全归一化"。

手算一个 4 维向量的 LayerNorm

拿一个 4 维小向量完整算一遍：x = [2, 4, 4, 6]，为简单起见取 γ = [1,1,1,1]、β = [0,0,0,0]、ε ≈ 0。

第一步：求均值。

μ = (2 + 4 + 4 + 6) / 4 = 16 / 4 = 4

第二步：每个分量减均值。

x − μ = [2−4, 4−4, 4−4, 6−4] = [−2, 0, 0, 2]

第三步：求方差（各偏差平方的平均）：

σ² = ((−2)² + 0² + 0² + 2²) / 4 = (4 + 0 + 0 + 4) / 4 = 2

第四步：除以标准差。 √2 ≈ 1.414：

LN(x) = [−2/1.414, 0/1.414, 0/1.414, 2/1.414] ≈ [−1.414, 0, 0, 1.414]

验算一下：新向量均值 = (−1.414 + 0 + 0 + 1.414)/4 = 0，方差 = (2 + 0 + 0 + 2)/4 = 1。完美归一。注意它保留了原来"两头高中间平"的形状信息，只是把音量调到了标准档。

如果 γ = [2, 2, 2, 2]、β = [1, 1, 1, 1]，结果就变成 [−1.828, 1, 1, 3.828]——网络通过学 γ 和 β，可以微调每个分量归一化后的尺度与偏移。

LayerNorm 与 BatchNorm：按"行"还是按"列"？

学过卷积网络的读者会问：这和 BatchNorm（批归一化）有什么区别？区别在归一化沿着哪个方向算均值方差：

BatchNormLayerNorm
归一化方向对每个特征，跨整个批次的样本算均值方差（"按列"）对每个样本（每个词），跨它自己的所有特征算（"按行"）
依赖批次大小？是。批次小、或推理时只有一个样本，统计就不稳否。每个词只依赖自己，批次大小、序列长度都无所谓
训练/推理行为不一致（推理时用训练时累积的移动平均）完全一致
主战场计算机视觉（图像批次统计稳定）NLP / Transformer

为什么 NLP 偏爱 LayerNorm？两个朴素理由。第一，句子长短不一：一批句子里有的 5 个词、有的 50 个词，BatchNorm 那种"跨样本统计同一个位置"的做法在参差不齐的序列上很难稳定。第二，推理时可能一次只处理一句话（比如你和 ChatGPT 单聊），BatchNorm 依赖"批"的统计量，单样本场景下行为会和训练时不一致；LayerNorm 只看当前这一个词向量自身，一句话、一个批次、一万个批次，行为完全相同。

5.7 Pre-LN 与 Post-LN：归一化放在里面还是外面？

残差连接和 LayerNorm 组合时有一个微妙的顺序问题，两种摆法都对 Transformer 的历史产生了深远影响：

  • Post-LN（2017 原论文的做法）：先残差相加，再归一化——LN(x + Sublayer(x))。归一化在残差之后（"post"）。
  • Pre-LN（后来研究提出、现代大模型几乎标配）：先归一化输入，子层输出再直接加回原始 x——x + Sublayer(LN(x))。归一化在子层之前（"pre"）。

为什么 Pre-LN 更稳？关键还在那条"高速公路"。Post-LN 中，主干道上的信号每一层都要被 LN 重新洗一遍均值方差，深堆叠时这条通道被反复"重新定标"，训练初期梯度容易剧烈波动，往往需要配合精细的学习率预热（warmup）才能训起来。Pre-LN 中，x 的残差通路从第一层直通最后一层，中间不被任何 LN 截断，梯度可以畅通无阻地一路回传，所以几十层的模型也能直接开训。代价是 Pre-LN 每层"支路"贡献的变化比例不同，理论上表达上限略受影响——但实践中"训得动"远比"理论上限"重要。GPT-2 之后的绝大多数大模型（包括 LLaMA、GPT-3 谱系）都用 Pre-LN 或其亲戚 RMSNorm。

5.8 拼起来：一个编码器层的完整 Add & Norm 数据流

5.10 小结

  • FFN 是每个词"独立思考"的车间：FFN(x) = max(0, xW₁+b₁)W₂+b₂，形状旅程 [512] → [2048] → [512]，先升维 4 倍便于分离特征、再压回原尺寸。
  • FFN 是 position-wise 的：同一个 FFN 独立作用于每个位置，词与词不交流——交流是注意力的职责。这种独立性带来了并行计算的便利。
  • FFN 占了每个编码器层约 2/3 的参数（约 210 万 vs 注意力约 105 万），常被认为是模型存储知识的地方。
  • 残差连接 x + Sublayer(x) 像编辑的修订模式：信息不丢；反向时 ∂(x+F(x))/∂x = 1 + ∂F/∂x 中那个 "1" 构成梯度高速公路，治愈深层网络的梯度消失。
  • LayerNorm 对每个词的向量单独做"减均值、除标准差"，再用可学习的 γ、β 微调；它按"行"归一化，与批次无关，这是它胜过 BatchNorm 成为 NLP 标配的原因。
  • Post-LN（原版）= LN(x + Sublayer(x))；Pre-LN（现代）= x + Sublayer(LN(x))。Pre-LN 的残差通路不被归一化打断，深层训练更稳定，是现代大模型标配。
  • 一个编码器层的完整数据流（Post-LN）：h₁ = LN(X + MHA(X))，h₂ = LN(h₁ + FFN(h₁))；全程形状不变，所以能像积木一样堆叠。

常见误区

  • "FFN 里词与词会互相看到"——错。两次矩阵乘法只在特征维混合，每个位置完全独立。想交流请找注意力。
  • "残差连接是为了让前向传播更快"——不是。它几乎不增加计算量（一次加法），它救的是训练（梯度回传）和信息保留，不是推理速度。
  • "LayerNorm 是在整个批次上算的"——那是 BatchNorm。LayerNorm 只看当前这一个词向量自己的 512 个数字，批次里有多少句子、句子多长，都与它无关。
  • "归一化把信息洗没了"——LN 保留向量的"形状"（分量间的相对大小关系），只调整尺度；何况 γ、β 给了网络"反悔"的能力。
  • "升维是浪费，反正要压回来"——升维段配合 ReLU 才是 FFN 表达力的来源；没有中间的高维空间，两个线性层直接相乘就退化成一次线性变换。

5.11 常见问题 FAQ

① 为什么 FFN 要先升维再降维，直接在 512 维做不行吗？

不行，关键卡在「两个线性层直接相乘会退化」：如果没有中间的 2048 维和 ReLU，xW₁W₂ 等价于一个 512×512 的单次线性变换，整个 FFN 就只剩下「旋转 + 缩放」，毫无非线性表达能力。升到 2048 维相当于把纠缠的特征摊到一张 4 倍大的工作台上，ReLU 才能逐个特征做「留下/清零」的筛选——表达力来自「高维空间 + 非线性筛选」这对组合，而不是升维本身。最后压回 512 维则是为了对接残差连接（形状必须一致）和下一层堆叠，见 5.5 节和 5.8 节。

② 残差连接不就是抄近道吗，会不会让中间层学不到东西、变成摆设？

恰恰相反，残差让中间层「敢学也学得动」。前向上，子层学的是「增量修正」F(x)，原信息 x 永远保底，所以就算某层暂时没学到有用的东西（F(x)≈0），网络也退化成恒等传递，不会比浅层更差——这让堆层变成安全的事。反向上，∂(x+F(x))/∂x = 1 + ∂F/∂x 中那个「1」保证每一层都能收到几乎不衰减的梯度信号（5.5 节），深层的每一层都被有效地训练，而不是被晾在一边。没有残差的深网络才会真的「中间层学不到东西」——因为梯度根本传不到它们。

③ LayerNorm 为什么按特征归一（对词向量内部算均值方差），而不是按样本？

「按特征」指的是对每个词自己的 512 个分量算均值方差，每个词只依赖自己，与批次里有几句话、句子多长完全无关。NLP 的句子长短不一、padding 混杂，BatchNorm 那种「跨整个批次、对同一位置统计」的做法在参差不齐的序列上很难稳定；而且推理时常常一次只处理一句话，批统计量根本不存在（5.6 节的对比表）。把不同词的统计量混在一起也不合理——「我」和「深度学习」的向量尺度没有可比性。LayerNorm 让每个词独立地被调回标准音量，训练和推理行为完全一致，这就是它成为 Transformer 标配的原因。

④ 层数是不是越多越好？

不是。加深确实通常提升表达能力，但代价有三：一是训练难度——没有残差和合适的归一化布局（如 Pre-LN，见 5.7 节），几十层根本训不动；二是参数和算力随层数线性增长，推理也更慢；三是超过数据量能支撑的深度后，收益迅速递减甚至过拟合。实际数字都是权衡出来的：原论文 base 用 6 层，BERT base 用 12 层，GPT-3 堆到 96 层——是「数据、算力、稳定性技术三者到位」之后才敢加深的，而不是层数本身有魔力。

5.12 自测题

① 原论文中 FFN 的参数量约为多少？为什么 FFN 最后必须压回 d_model 维？

约 210 万（W₁: 512×2048，b₁: 2048，W₂: 2048×512，b₂: 512，合计 2,099,712）。必须压回 512 维有两个原因：其一，残差连接要求子层输出与输入形状相同才能相加；其二，输出要喂给下一个编码器层，形状必须保持不变才能堆叠。

② 设输出 y = x + F(x)，某一层 F 的导数 ∂F/∂x ≈ 0.01，那么梯度穿过这一层后大约保留多少？如果没有残差呢？

有残差时 ∂y/∂x = 1 + 0.01 = 1.01，梯度几乎无损通过（甚至略放大）。没有残差时梯度要乘以 0.01，只剩百分之一；这样的层堆叠十几层后梯度就衰减到 10⁻²⁰ 量级，前面的层完全收不到训练信号。这就是残差连接治愈梯度消失的算术本质。

③ 为什么 NLP 模型普遍用 LayerNorm 而不是 BatchNorm？请给出至少两个理由。

① NLP 批次内句子长短不一、padding 混杂，BatchNorm 跨样本统计同一位置的均值方差会不稳定，LayerNorm 只依赖每个词自身，与批次无关；② 推理时常常一次只处理一个样本，BatchNorm 的训练/推理行为不一致（需移动平均），LayerNorm 两种模式完全一致；③ Transformer 中不同位置（不同词）语义差异极大，把它们的统计量混在一起归一化本身就不合理。
